Horario dinámico

Selecciona nivel y actividad, carga/edita tu JSON y pinta el horario.

Fuente de datos (JSON)

Formato mínimo soportado (como el del ejemplo adjunto): [{ "codigo": "INDG1801", "hora_inicio": "08:30:00", "hora_fin": "10:00:00" }, ...]

Para ubicar automáticamente por día/nivel/actividad, también puedes usar el formato extendido por ítem (opcional): { "dia": "Lunes|Martes|Miércoles|Jueves|Viernes", "nivel": "100 - I", "actividad": "Clases" }.

Si el JSON no incluye dia, podrás asignarlo en la sección "Asignación de días" más abajo.
